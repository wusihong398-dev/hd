## 新增功能
1. 健康总览增加严重、警告、关注、良好、数据不足、无法读取六类风险计数卡片。
2. 800 格扫描网格支持点击定位，显示该格对应的字节范围、扫描覆盖状态，以及落在该范围内的已记录读取错误/复测慢速位置。该范围是热力图比例映射，不伪造扇区号或 LBA。
3. 历史趋势在现有图表下增加最近两次有效采集的差值说明；累计计数器回退会提示核对设备身份，不按负增长判定健康。
4. 新增本地 SQLite 风险提醒表；按设备身份与证据指纹去重，默认 6 小时冷却，支持查看提醒历史和标记已查看。
5. 新增 Windows 登录后自动 SMART 检测设置，默认关闭；只在用户主动启用后创建当前用户登录触发任务。
6. 新增无管理员权限的自动检测辅助 EXE。任务只运行 SMART 读取，不运行坏道扫描；需要管理员权限的设备会显示读取受限，不当作硬盘损坏。
7. 新增中文 PDF 报告，支持全部硬盘或当前所选硬盘，使用 ReportLab 简体中文 CID 字体。
8. 保留 v0.5.0 的健康总览、智能诊断、HTML/JSON 报告、SMART 自检、历史档案和只读坏道扫描。

## 安全与隐私
- 自动检测默认关闭；不创建 SYSTEM 服务，不上传硬盘信息。
- 自动检测任务以当前用户登录会话和 LIMITED 权限运行。
- 主程序仍保留管理员启动清单，以兼容原有需要管理员权限的物理盘只读扫描。
- 自动检测辅助 EXE 不带管理员启动清单，避免开机检测触发 UAC。
- 不执行修复、写零、格式化、擦除、重映射或扫描写入。
- SMART 不支持、透传失败和读取受限均显示为数据不可用，不直接判定硬盘损坏。

## 使用提示
- 日常手动使用：运行 `硬盘健康卫士.exe`。
- 如需登录后自动检测：从 ZIP 解压两个 EXE 到同一文件夹，运行主程序，在“自动检测设置”中主动勾选。不要单独移动或删除辅助 EXE。
- 关闭自动检测：在同一设置页取消勾选。
- PDF：先执行“全部硬盘 SMART 检测”，再到“报告中心”导出全部硬盘或当前硬盘 PDF。
