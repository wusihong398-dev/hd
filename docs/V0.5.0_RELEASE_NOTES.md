# 硬盘健康卫士 v0.5.0 发布记录

## 本次新增
- 新增“健康总览”页面：展示全部物理硬盘、介质类型、健康状态、风险等级、评分、温度、剩余耐久度（仅可靠数据可用时）和 SMART 可用性。
- 新增逐盘诊断详情：展示诊断结论、SMART 证据、风险提示、历史变化和建议。
- 新增“报告中心”：支持导出全部硬盘中文 HTML 或 JSON 报告。
- 报告包含硬盘型号/容量/盘符映射、脱敏序列号、介质识别、SMART 诊断、属性与指标、自检历史、健康历史和安全说明。
- 使用稳定硬盘身份匹配历史结果，避免重新枚举后仅凭 PhysicalDrive 编号误关联。
- 保留 v0.4.1 的只读坏道扫描和彩色网格、自检自动轮询、现有健康历史。

## 诊断原则
- SMART 读取失败、设备不支持或控制器透传失败显示为无法读取/数据不足，不直接判定硬盘损坏。
- 评分来自已有诊断规则；证据不足时不伪造分数。
- SSD 剩余耐久度只在设备提供可靠字段时展示；不推算剩余使用年限。
- 黄色慢速区块不是确认坏道；红色读取错误也需结合复测及设备信息判断。
- 软件不自动执行修复、写零、格式化、擦除或重映射。
