# 硬盘健康卫士 v0.6.0 开发计划

## 版本目标
基于 v0.5.0 的源码补丁链继续迭代，强化可视化风险、扫描定位、历史趋势、异常提醒、开机自动检测和 PDF 报告。保留所有现有功能与历史数据。

## 强制安全原则
- 自动检测只读取 SMART 和已有只读扫描结果，不执行修复、写零、格式化、擦除、重映射或写入测试数据。
- 开机自动检测默认关闭，必须由用户主动开启；提供明确关闭入口。任务只在当前 Windows 用户登录后运行，不以 SYSTEM 或管理员身份创建后台持久任务。
- 所有通知都基于已采集到的明确风险证据；SMART 读取失败、设备不支持和 USB/RAID 透传失败不得作为硬盘损坏结论。
- 通知应去重/冷却，避免每次轮询重复弹窗；用户可以查看历史提醒。
- PDF 报告必须包含生成时间、设备身份和采集限制；中文字体正确，写入失败显示原因。
- 所有历史趋势按稳定设备身份关联；身份质量不足时禁止跨盘合并。

## 1. 风险总览
- 在 v0.5.0 健康总览中增加风险分布摘要、风险硬盘突出显示和最近检查时间。
- 显示“严重/警告/关注/良好/数据不足/无法读取”计数。
- 点击风险硬盘可跳转对应诊断详情；未知状态使用中性样式，不显示绿色健康。

## 2. 扫描热力图与定位
- 保留四色扫描网格；点击网格单元显示对应扫描范围、起止字节偏移、LBA（设备/扫描数据可可靠换算时）、读取耗时和错误码。
- 未扫描网格不得显示为正常。
- 扫描中、暂停、停止和完成状态的映射一致；扫描结果缺少定位信息时显示“该区块暂无可用定位数据”。
- 不将慢速区块标记为确认坏道；红色只代表读取错误/复查结果，报告需说明其局限。

## 3. SMART 历史趋势
- 新增趋势页面/视图，支持温度、通电小时、CRC、重映射、待映射、不可校正、NVMe Media Errors、Percentage Used。
- 以同一稳定身份的时间序列绘图，显示采集时间、当前值、上次值和变化量。
- 无字段/身份不确定时显示缺失原因，不插值、不补造、不混合设备数据。
- 对单调累计计数器识别新增变化；温度等瞬时指标只展示变化，不自动判定故障。

## 4. 异常增长预警
- 依据现有诊断规则和历史快照识别新增重映射/待映射/不可校正、CRC 增长、NVMe 介质错误增长和 Critical Warning。
- 预警区分介质风险、接口/连接风险和数据不可用。
- 对同一设备、同一指标、同一证据指纹去重；同一提醒在冷却期内不重复弹出。
- 提供提醒历史和确认/清除视图；清除提醒不改动硬盘或 SMART 数据。

## 5. 开机自动检测与通知
- 新增设置页：默认关闭“登录 Windows 后自动检测”。
- 用户主动开启后，仅为当前用户创建登录触发任务；不开启管理员级后台服务。
- 任务启动软件的自动检测模式；检测完成后在软件界面给出结果，若系统通知能力不可用则使用应用内提示。
- 提供立即测试通知、关闭自动检测、删除当前用户计划任务的操作。
- 不在应用启动时静默启用，不上传硬盘信息，不联网发送数据。

## 6. PDF 报告
- 新增单盘与全部硬盘 PDF 导出。
- 使用 ReportLab 的简体中文 CID 字体，避免中文乱码。
- 包含风险摘要、设备信息（序列号脱敏）、SMART 指标/属性、诊断依据、历史趋势、自检记录、扫描覆盖率/异常位置和限制说明。
- PDF 生成错误可见；原有 HTML/JSON 报告继续可用。

## 7. 自动化测试
- 趋势计算：同一设备、缺失字段、身份不确定、计数器回退、时间排序。
- 预警：新增计数、无增长、读取失败、去重、冷却、严重状态。
- 扫描热力图：单元格到偏移范围映射、未扫描状态、扫描完成/停止覆盖率。
- 自动检测任务：默认关闭、启用/禁用参数、路径含空格、安全参数和任务命令注入。
- PDF：中文文本、页眉页脚、生成时间、空数据、异常路径和文件不可写。
- 保留 v0.5.0 的全部 38 项测试。

## 8. 发布门槛
- 先审计 v0.5.0 补丁应用后的真实源码 API，再实施，不猜测函数名或盲目替换。
- 自动化测试、语法检查和 Windows x64 构建全部通过后才交付。
- CI 成功只代表构建和自动化测试成功；用户电脑 GUI、真实硬盘、Windows 登录任务、通知及 PDF 阅读器验收仍需实机确认。
- 提供 EXE、SHA256、ZIP、测试报告和已知限制。
